## 結論

### 予算を絞ったとき LLM・記憶は効くか（3行）

1. **LLM は、予算が少ないほど効く。** 予算10では、LLM の違いで最大 +16.7 ポイント（0.8M-15k 対 0.1M）の差がつき、総当たりとの差は +36 ポイント。予算2000ではこの差が消える（+1.3 ポイント、補正後は有意でない）。効くのはパラメータ数ではなく LLM 単体の強さで、学習量の多い 0.8M が 2.7M を上回った。
2. **長期記憶は、どの予算でも一貫した効果がない。** 予算10では −3.5〜−6.6 ポイント（有意に悪化）、予算50では +1.1〜+2.8 ポイント（有意に改善）、予算200・2000では、強い LLM（0.8M・2.7M）で −3 ポイント前後（有意に悪化）。今の設計のままでは既定で ON にする根拠がない。
3. **正解の出どころを見ると、予算2000で OOD-深さ を解いているのは組み合わせ探索（86〜91%）で、LLM が直接当てたものはほとんどない。** 予算50では、少ない正解の83%を LLM（直接＋サンプル）が出している。LLM は「予算が少ないときの近道」として効いている。

### その他の診断結果

- **アブレーション（Holm 補正後）**
  - 有意に効く: Router（+14.4）、LLM サンプル（+2.9）、組み合わせ探索（+2.4）。
  - 外すと有意に良くなる: 長期記憶（−3.3）、Experts（−1.0）。
  - 差なし: Critic。修復（Repair）は一度も実行されていない。
- **発見ループ（300個）**
  - 能動的な実験計画は有意に効く（+37 / −12）。
  - 好奇心（最も不確かな対象を選ぶ）は有意に悪化させる。外すと 84.3% → 92.3%。
  - 記憶は差なし。以前の「67% 対 68%」（24個）は問題数が少なすぎて差を検出できていなかった。
- **長期記憶が予算10で悪化する理由（推測、未検証）**: 記憶の段階は LLM のサンプリングより前にあり、少ない予算を記憶の候補（最大8個）の検証に使ってしまうため。

### 注意

- LLM の強さの順は、検証損失で 0.8M-15k（0.31）＞ 2.7M-8k（0.46）＞ 0.1M（0.67）。パラメータ数の順とは一致しない。
- OOD-組み合わせ は規則の種類が約85通りと少ない。
