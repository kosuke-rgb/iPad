## 結論

1. **LLM 単体は強くなるが、提案モデルの性能はほぼ一定**
   - LLM 単体の ID 正答率は 17%（2.7M-2k）→ 69%（0.8M-15k）と4倍になった。
   - 提案モデルの OOD-深さ は 54.7〜59.3%、OOD-関連 は 53.7〜60.7% でほとんど変わらない。
   - 性能を決めているのは、LLM の賢さではなく探索と検証の仕組み。
2. **性能 / 計算量が最も良いのは最小の 0.1M**
   - LLM の計算は 29 MFLOPs/問（2.7M の約1/25）、実行時間は 50ms/問（2.7M の約1/3.5）。それでいて正答率は同等。
3. **モジュールの寄与は LLM の強さにほとんど依存しない**
   - Router: +15〜16 ポイント（すべての LLM で最大）。
   - LLM サンプル: +3〜4 ポイント。
   - 組み合わせ探索: +8.0 → +2.9 ポイントと、LLM が強くなるほど寄与が小さくなる（LLM 自身が良い候補を出すため）。
   - Experts・Critic: どの LLM でも有意差なし。
4. **長期記憶は、最も強い LLM では有意に悪化させた**（−2.1 ポイント、p=0.011）
   - 主に OOD-深さ（58.0% 対 65.3%）で起きている。
   - 第2ラウンドで v2 の記憶が有意に効いたのは、初期の LLM（固定長パディングで学習した 0.8M-5k）の場合だった。
   - 記憶の効果は LLM によって向きが変わる可能性がある。フェーズ1（300問 × 3シード、予算別）で再検証する。

注: この実験は1分割100問。フェーズ1以降は300問に増やしている。
