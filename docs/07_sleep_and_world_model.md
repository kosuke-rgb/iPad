### 分かったこと（暫定）

- **睡眠で「経験によって自分が変わる」ことは起きた。**
  - 直感で解けた割合（LLM の最初の1回答で正解）: 17% → 23〜28%
  - 仮説の実行回数: 641 → 470
  - LLM 単体の OOD-深さ: 2% → 8%（元の学習にない3段階の規則を、自分の経験から学んだ）
  - 4日目の正答率: 62.7% → 69.3%（+16 / −6、p=0.053。有意の境界）
- **古い知識の復習がないと、破滅的忘却が起きた。**
  - 復習なしでは ID の LLM 単体正答率が 62% → 13〜27% に崩れた。脳が睡眠中に新旧の記憶を交互に再生するのと同じ理由。
  - 復習ありでも 62% → 52% に下がっている。忘却は完全には防げていない。
- **夢（同じ規則の新しい例）は効いている。** 夢なしでは、LLM 単体の OOD-深さ も直感の割合もほとんど伸びなかった。

## 2. 学習した世界モデル（1シード、180問）

- 予測の正確さ: 1手順 97.7%。ロールアウトは深さ1で99.3%、深さ2で95.3%、深さ3で89.7%。苦手なのは累積和（83%）と重複削除（82%）。
- 現実での実験回数の上限と正答率:

| 上限 | 現実のみ | 想像→現実 | 想像のみ（現実0回） |
|---|---|---|---|
| 1回 | 33.9% | 67.2% | 64.4% |
| 5回 | 50.0% | 68.9% | — |
| 無制限 | 68.3%（平均77回） | 68.9%（平均49回） | — |

- 想像で観測と合った候補の 99.9% が、現実でも合っていた（適合率）。現実で合う候補の 96.2% を、想像で見つけられた（再現率）。
- ただし、想像の計算は1問あたり 14.8 GFLOPs と重い（LLM の約70倍）。

## 次にやるべき検証

- 睡眠: 3シード × より多くの問題で再検証する。復習ありでも残る忘却を減らす（復習の割合、学習率）。
- 世界モデル: 3シード × 300問で再検証する。軽量化（小さなモデル、KV キャッシュ）。
